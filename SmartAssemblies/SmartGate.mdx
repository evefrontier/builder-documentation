# Smart Gate

The **Smart Gate** is a [Smart Assembly](/SmartAssemblies) that can be deployed in space to support transport across space. **Smart Gates** allow you to link crucial systems, making transport far easier and more convenient. **Smart Gates** function by linking to another one, creating a transport link that allows players to travel.

**Smart Gates** allow you to decide who can use them, allowing for strategic opportunities in **EVE Frontier**. 

To deploy **Smart Gates**, they need to be at least 20KM away from any other **Smart Assembly** and there cannot be more than five in one system.

**Smart Gates** can only be linked with ONE other **Smart Gate** at a time and the two gates must be owned by the same character.

By default **Smart Gates** are configured to allow any player to use them.

## Smart Gate Controller Logic
### canJump
This controller function can be configured to allow (or disallow) players to use the **Smart Gate**. You can use this to create gates that will, for example, only work for allies, only function at certain times, or only work for players who pay a toll.
