# GAS Faucet

In this guide, you will be able to get GAS in **Eve Frontier.**

{% hint style="info" %}
Pre-requisites

To follow this guide, you need to make sure to follow both the [Wallet Game Setup](/broken/pages/64ebbb78fcdbc93a6166b6b8ff7653cd788a0107) and the [Browser Extension](/broken/pages/df29d74ebe461864c08174d6abb22b6b761741a1) guides.
{% endhint %}

## Guide

{% stepper %}
{% step %}
### Visit

Head to the OP Sepolia faucet hosted by GHOST: [https://ghostchain.io/faucet/ethereum-sepolia/](https://ghostchain.io/faucet/ethereum-sepolia/) and click on **Connect Wallet**.
{% endstep %}

{% step %}
### Connect Wallet

Next, select One Key as your Wallet. This is the EVE Vault wallet.
{% endstep %}

{% step %}
### Authorize

There should be a new popup window that asks to connect to the website. Press the Connect button.
{% endstep %}

{% step %}
### Receive

Now your wallet should be connected, you can select the Receive button.
{% endstep %}

{% step %}
### Confirm

Now, you can go to the **EVE Vault** either in the game, or in your browser extension. You should see roughly 0.01 additional Sepolia ETH (the OP Sepolia testnet gas token).
{% endstep %}
{% endstepper %}
