## Introduction

This guide explains the Smart Gate system for EVE Frontier on SUI. You’ll learn how gates are modeled as Move smart contract objects, how builders and players can deploy and manage gates, how to configure access with programmable logic, and how to test gate operations using the latest contracts and scripts from the [`evefrontier/world-contracts`](https://github.com/evefrontier/world-contracts) repository.
