# Contributing to EVE Frontier

Welcome to the contributing guide for the EVE Frontier. We want to create a community for Builders to grow and where everyone feels empowered to participate in improving EVE Frontier.  We're excited to have you join us on this journey.  

## Why Contribute?

This journey were on with EVE Frontier and open-source will never be done or it's documentation.. we are here for the long haul and hope to bond with the community through this collaboration.  Contributing to the docs is a good way to take part in the journey and make everything better for us all.

We're all in this together and you might have ideas on how to improve the documentation or builder examples. This page will guide you through implementing your ideas to contribute to the community.

## How to Contribute

Feel free to checkout the docs repo (LINK) and the readme file there will explain how to get it up and running locally.  Whatever you want improved; typo or a big change to improve everyone understand things better... just push a pull request.
