# Browser Extension

{% hint style="info" %}
These steps assume you have already created your in-game characters which automatically create your wallet. For info on how to set up the wallet in-game see [Wallet game setup](/broken/pages/7afa6b6fa5c577a25d33060a1c342ba628ed7940).
{% endhint %}

The EVE Vault extension is only available for the Google Chrome browser at this time. Please [download and install Chrome](https://www.google.com/chrome/) before continuing.

{% hint style="warning" %}
If you have installed EVE Vault in the past, please uninstall it, and then follow these instructions. Earlier versions will conflict with the new EVE Vault and may cause it to break.
{% endhint %}

{% stepper %}
{% step %}
### Download the Extension

Download the EVE Vault browser extension:\
https://artifacts.evefrontier.com/wallet/extension/vault-v1.1.1/wallet-alpha.zip
{% endstep %}

{% step %}
### Unzip the Extension

In your download folder, unzip the extension file. This creates the _wallet-alpha_ folder.
{% endstep %}

{% step %}
### Visit Chrome Extension Management

Open Google Chrome and visit:\
chrome://extensions
{% endstep %}

{% step %}
### Enable Developer Mode

In the top-right corner of the Extensions tab, enable **Developer Mode**.
{% endstep %}

{% step %}
### Install the EVE Vault Extension

Click **Load Unpacked**, and choose the **wallet-alpha** folder. Chrome adds the EVE Vault extension.
{% endstep %}

{% step %}
### Open EVE Vault

Click **Extensions** (the puzzle piece), and then click **EVE Vault**. The EVE Vault window opens.
{% endstep %}

{% step %}
### Import your Wallet

Click **Import Wallet**, then enter the _recovery phrase_ you created when you set up your wallet, and click **Confirm**. The recovery phrase is also called the _mnemonic passphrase_ and you can access it through the game client:

In the game client: click the Wallet icon on the left, then the cog wheel in the Wallet window and select **View recovery phrase** to view your _mnemonic passphrase_.
{% endstep %}

{% step %}
### Create a Password

On the Set Password screen, enter and confirm a password of at least eight characters, and then click **Continue**. This password encrypts your data and is used to unlock EVE Vault in the future.

**NOTE:** Save this password in a secure location (we recommend [1Password](https://1password.com/)). There is no way to recover the password at this time.
{% endstep %}
{% endstepper %}

Congratulations! Your wallet is ready in EVE Vault and is linked to your character's in-game wallet: click **Enter** to view your character's wallet in the EVE Vault.

To access EVE Vault quickly in Chrome, pin the extension:

* Click the puzzle icon (Extensions).
* Select the **EVE Vault** pin icon so it turns blue.

Having issues? Please let us know on [Discord](https://discord.com/invite/evefrontier).
