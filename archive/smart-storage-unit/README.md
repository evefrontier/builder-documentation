# Smart Storage Unit

## Introduction

This guide will walk you through the process of building contracts for the **Smart Storage Unit** example, deploying them into an existing world running in Docker, and testing their functionality by executing scripts.

## Example Functionality

This example is for a [SSU (Smart Storage Unit)](/broken/pages/e8ba08208bf6c366a99e32c95cb57750e0816e99) in the game which can be set up to automatically trade items between the owner and other players. Prices are set by providing a ratio of items. For example, with a ratio of 1:2 you can exchange 1 ore for 2 mining lenses.
