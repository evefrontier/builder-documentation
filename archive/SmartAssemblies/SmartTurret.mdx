# Smart Turret

The **Smart Turret** is a [Smart Assembly](/SmartAssemblies) that can be attached to the surrounding space of other **Smart Assemblies**. The **Smart Turret** can be used to project offensive or defensive power over a single location.

To deploy a **Smart Turret**, it needs to be within 25KM of any other owned **Smart Assembly** as it attaches to it when deploying.

## Fitting
To interact with a **Smart Turret**, simply right click it after it’s been deployed and click “Interact”. The **Smart Turret** is then fitted with a single module which can be any module which affects other ships remotely such as weapons or interdiction modules. They behave in the exact same way as if the module was being used by a player in their Ship. If the fitted module takes charges or ammunition then it is placed into the turret's inventory and is consumed upon use.

## Anchoring
A **Smart Turret** can only be deployed into space by attaching it to another **Smart Assembly** of the same owner, such as a **Smart Storage Unit** or a **Smart Gate**. The current limitation is that there can only be three **Smart Turrets** attached to another **Smart Assembly**.

## Smart Turret Logic Controllers
**Smart Turrets** have two primary logic controllers which can be set by the owner of the **Smart Turret** for different events that can be acted upon by the turret: **InProximity** and **Aggression**.

### InProximity
**InProximity** will detect any characters / ships which enter the detection range (determined by the distance of the fitted module). The **InProximity** event is calculated automatically by the game server and passed to the turret's on-chain controller. This is done independently for each **Smart Turret** connected to another **Smart Assembly**. 

### Aggression
**Aggression** will detect any character / ships within range of the turret that take an offensive action against another ship within the **Smart Turret**'s range. Similarly, the **Aggression** event is tracked by the game server and passed to the turret's on-chain controller; independently for each **Smart Turret**.

### Priority Queue & Targeting
**Smart Turrets** have a few different parameters which allow control over how it prioritizes and changes targets. This is done through a list of targets which are ordered by weight depending on a few parameters which are normally observable in-game (the **Priority Queue**).
The logic for the targeting controllers of a **Smart Turret** is managed in an on-chain smart contract.

When a new target enters the **Smart Turret**'s range in-game (**InProximity**), or when a new target attacks another ship (**Aggression**) the game will pass a list of pre-existing targets in range (in ascending order of priority - meaning the highest priority target is the last target in the list) along with the new target's details. Given this information, it is the job of the controller logic to determine which targets to fire upon, and in what order. It does this by returning a curated list of the **Priority Queue**, either including or excluding targets from the original list, and reordering any included targets in ascending order of priority. By default:

- the **InProximity** controller will tell the turret to fire upon any target within range that is _NOT_ in the **Smart Turret** owner's tribe. New targets are added as the last element of the **Priority Queue** (and therefore have highest priority).

- the **Aggression** controller will tell the turret to fire upon any aggressor target within range that is _NOT_ in the **Smart Turret** owner's tribe. New targets are added as the last element of the **Priority Queue**.
