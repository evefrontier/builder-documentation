# Decentralized Applications

**Decentralized applications (DApps)** are applications whose state and logic are stored on the blockchain, and can interact with the EVE Frontier World. This is in contrast to standard applications, which are designed to run on one system. In many cases, DApps run on Ethereum blockchains. Traditionally, DApps are open-source, but that is not required.

Much of what you'll do as you build on the Frontier is design and construct your own DApps, which will take you to places you've only dreamed of before.

## Creating DApps

Follow the documents in this section in the order they're listed in the site navigation, starting with [DApp Quick Start](https://github.com/evefrontier/builder-documentation/blob/Main/Dapp/quick-start/README.md). Together they provide a tutorial that guides you through creating your own DApps.
