# Connecting From An External Browser

The DApp uses the EIP-6963 Multi Injected Provider Discovery Standard to discover providers that are injected into a web browser. Two wallets are currently supported in the DApp: [Eve Vault](/broken/pages/55508ec4c5b56b2a61f55e8310f08c887a4e985c) and [Metamask](https://metamask.io/).

Follow these steps to navigate the DApp in an external web browser.

{% stepper %}
{% step %}
### Open the DApp in a browser

Open a browser and connect to [http://localhost:3000](http://localhost:3000/). You can view what it might look like here: [https://smart-assembly-base.stillness.evefrontier.com](https://smart-assembly-base.stillness.evefrontier.com/).
{% endstep %}

{% step %}
### Install EVE Vault (if needed)

If you do not already have the EVE Vault installed in your browser, click **Please Install EVE Vault** and follow the steps to install the vault.
{% endstep %}

{% step %}
### Or connect with Metamask

Alternatively, you can connect to the DApp with Metamask.
{% endstep %}
{% endstepper %}
