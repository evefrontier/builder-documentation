# Smart Gate

## Introduction

This guide will walk you through the process of building contracts for the [**Smart Gate**](/broken/pages/985ede378a4a8e3dfd8d4b33da7df82cb88a8132) example, deploying them into an existing world running in Docker, and testing their functionality by executing scripts and unit tests.

## Example Functionality

This example is for a [**Smart Gate**](/broken/pages/985ede378a4a8e3dfd8d4b33da7df82cb88a8132) in the game which only allows members of a specified Tribe access.

## Pre-Requisites

Make sure you have setup your tools with [this guide](/broken/pages/913027044a4553eb71a12e64225ec7607419b983) and your world if you are testing locally with [this guide](/broken/pages/47a9cdeaeed0c84937ad7bfed5981b8ece2e6e51).
