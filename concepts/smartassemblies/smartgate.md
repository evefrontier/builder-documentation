# Smart Gate

## Introduction

This guide will walk you through the process of building contracts for the [**Smart Gate**](../../SmartAssemblies/SmartGate/) example, deploying them into an existing world running in Docker, and testing their functionality by executing scripts and unit tests.

## Example Functionality

This example is for a [Smart Gate](../../SmartAssemblies/SmartGate/) in the game which only allows members of a specified Tribe access.

## Pre-Requisites

Make sure you have setup your tools with [this guide](../../Tools/) and your world if you are testing locally with [this guide](../../LocalWorldSetup/).
