# Smart Gate

![](./images/banner5.png)

## Introduction
This guide will walk you through the process of building contracts for the <strong>[Smart Gate](/SmartAssemblies/SmartGate)</strong> example, deploying them into an existing world running in Docker, and testing their functionality by executing scripts and unit tests. 

## Example Functionality
This example is for a [Smart Gate](/SmartAssemblies/SmartGate) in the game which only allows members of a specified Tribe access.

## Pre-Requisites
Make sure you have setup your tools with [this guide](/Tools) and your world if you are testing locally with [this guide](/LocalWorldSetup).
