# Smart Storage Unit

![](./images/banner5.png)

## Introduction
This guide will walk you through the process of building contracts for the <strong>Smart Storage Unit</strong> example, deploying them into an existing world running in Docker, and testing their functionality by executing scripts. 

## Example Functionality
This example is for a [SSU (Smart Storage Unit)](/SmartAssemblies/SmartStorageUnit) in the game which can be setup to automatically trade items between the owner and other players. Prices are set by providing a ratio of items. For example with a ratio of 1:2 you can exchange 1 ore for 2 mining lenses.

## Pre-Requisites
Make sure you have setup your tools with [the Tools guide](/Tools) and your world if you are testing locally with [the World Setup guide](/LocalWorldSetup).
