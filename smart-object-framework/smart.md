# Smart Contracts

## Smart Contracts

Smart Contracts are the foundation of the functionality for **Smart Assemblies**. Here you can find information on how to develop Smart Contracts for your **Smart Assemblies**.

### What are Smart Contracts?

Smart Contracts is the name given to programs in a blockchain environment. We use a blockchain because [Ethereum-style blockchains](https://ethereum.org/en/) provide an execution environment that runs programs separately, protecting them from interference from other users. No bug in your code will cause the game to crash, and no hacker will be able to steal your resources unless your own code allows it.
